El resultado de la interpretabilidad
— se lleva el tipo de buque cuando el modelo ve el tamaño y la velocidad

Con la información mínima explicaba el 41,6 %. No es que el tipo de buque dejara de importar: nunca fue la causa. Estaba haciendo de sustituto del tamaño y de la operación, que no se habían medido.

La lección más transferible del trabajo: una variable categórica dominante debe mirarse siempre con sospecha. Una etiqueta administrativa no es un mecanismo físico; si explica mucho, lo normal es que esté tapando algo que no se ha medido.

El número accionable: lo que cuesta una hora de navegación

Toneladas de CO₂ por hora navegada, por tipo de buque. Es lo que convierte el modelo en una decisión: dice dónde rinde más cada hora que se deja de navegar.

Desde qué país se paga la factura europea

La única dimensión geográfica que el registro público permite: el país del puerto de registro del buque, reconstruido de una columna que el proyecto no había usado nunca y que cubre el 96,4 % de las emisiones de 2025.

 

Cómo está hecho esto, en cinco frases

1. El modelo predice el CO₂ anual de un buque a partir de datos públicos: tipo, horas de mar, velocidad media y capacidad de carga reconstruida. R² 0,948 sobre buques que nunca vio.
2. El ahorro de un plan se mide predicho contra predicho, nunca contra el dato declarado: así el error del modelo en cada buque se cancela al restar.
3. Las horas de mar no se fijan a mano: se deducen de millas = horas × velocidad, de modo que no puede construirse un plan físicamente imposible.
4. El panel no calcula nada. Cada cifra de esta pantalla es una respuesta literal del servicio, que a su vez importa el mismo módulo que ejecuta el cuaderno del trabajo.
5. La palanca de velocidad está infravalorada a propósito: la velocidad publicada es una media anual que mezcla navegación con tiempo parado, así que su efecto es una cota inferior.
